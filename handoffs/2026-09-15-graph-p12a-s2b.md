- **`runner.py`:**
  - `tick` calls only `advance`, which runs admit → manifest → one resolve → `claim(deadline_sec=)` → store manifest → `dispatch`.
  - A wait adds to `report.waiting` and claims nothing.
  - A block or a manifest refusal goes through `_refuse`, which claims and then calls `_fail_claim`. `_fail_claim` is shared with launch failure.
  - `Claim` has `binding`, `plan`, `manifest_artifact_id` and `session`.
- **Refusal reasons live in a `RouteRefused` store event for now.** Step B adds the `route_refusal` attempt column (S-8) and records the reason there.
- **Worker argv:** effort args are passed as `--effort-arg=<a>` (with `=`), because each value is itself a flag.
- **Worker runtimes:** `worker.py` runs `ModelAgentRuntime` for `model_endpoint_harness` through a replaceable `_model_api`. For `agent_cli` it runs `driver.complete` before adopting the workspace.
- **`orchestrator._graph_routing()`:** built once in `_graph_main`, which passes an `ArtifactStore` to every runner and writes route waits through `_record_admission_waits`. If routing can't be built, it journals `runner_config_error` and returns 1.
- **Pool slots:** `resources` is not reserved after binding. The design didn't specify it; leave it unless W8 needs it.
- **Lane harness:** `LaneScenario.routing` defaults to an inert fixture (`FixtureQueries`, `fixture_cli_entry`, `fixture_routing` in `tests/graph_engineering/conftest.py`).
