## Method

Use `superpowers:subagent-driven-development`, with the wave-2 adaptations:

- **Worktrees on persistent storage**, never `/tmp`: `git worktree add /home/dan/.maestro-sdd/wt-<item> -b sdd/<item> <master head>`.
  This saved uncommitted work across **four** separate rate-limit waves this session.
- **Every implementer runs the suite in the foreground with a 600000 ms tool timeout, and commits as
  soon as it is green.** Never background; a subagent that ends its turn waiting on a background run
  is stranded.
- **Give reviewers a named risk, not a checklist.** Every finding of consequence this session came
  from one: A4's dead trigger, C3's missing template key, C7's understated bound.
- **When you spot a probable defect yourself, hand it to the reviewer as an open question rather than
  ruling on it.** Twice this session that returned confirmation *with evidence the controller did not
  have*.
- **Rate limits:** four waves hit this session. If several agents die at once on a 429, stop
  dispatching rather than burning the queue against it, and resume after the stated reset.
